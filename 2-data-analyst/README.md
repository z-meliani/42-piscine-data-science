# Piscine Data Science - Data Analyst

The `Data Analyst` project serves as an accessible entry point into data visualization and consumer behavior analysis.


## 🏗️ Project Architecture

```bash
.
├── .venv/
├── data/
├── src/
│   ├── ex00
│   ...
│   └── ex04
└── requirements.txt
```

## ⚙️ Setup

Run the following to create a virtual environnement with the needed libraries:

```bash
# Create a virtual environment in the current directory
python3 -m venv .venv

# Activate the virtual environment
source .venv/bin/activate

# Install dependencies from pyproject.toml
python3 -m pip install -r requirements.txt
```
