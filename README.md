# Piscine Data Science - Data Engineer

The Piscine Data Science is a collection of five projects introducing students to three key roles in data: `Data Engineer`, `Data Analyst`, and `Data Scientist`.


## 📚 Overview
### 0 - Data Engineer

This module is a light entry project to database creation and manipulation where you setup a PostgresSQL database within a container and creates tables from CSV files.


| Exercise | Description |
|----------|-------------|
| ex00 | PostgreSQL database setup and configuration |
| ex01 | Database GUI visualization and management |
| ex02 | Single CSV to PostgreSQL table creation |
| ex03 | Automated multi-CSV PostgreSQL table importing |
| ex04 | Items table creation from CSV file |


---
### 1 - Data Warehouse

This module serves as a foundational introduction to the ETL (Extract, Transform, Load) pipeline. It demonstrates the process of taking raw, fragmented data and turning it into a structured, queryable database.

| Exercise | Description |
|----------|-------------|
| ex00 | Database client connection and schema exploration |
| ex01 | Data consolidation using SQL union operations |
| ex02 | Data deduplication and temporal record cleaning |
| ex03 | Relational table merging and schema integration |


---
### 2 - Data Analyst

This module serves as an accessible entry point into data visualization and consumer behavior analysis.

| Exercise | Description |
|----------|-------------|
| ex00 | Proportional categorical data visualization using pie charts |
| ex01 | Time-series trend analysis using line and bar charts |
| ex02 | Descriptive statistics calculation and box plot outlier analysis |
| ex03 | Distribution plotting using histograms and frequency bar charts |
| ex04 | Optimal cluster evaluation using the Elbow Method |
| ex05 | Unsupervised customer segmentation using clustering algorithms |

---
### 3 - Data Scientist 1

This module lets you explore the foundations of data science, including data correlation factors, dataset splitting, and data standardization.

| Exercise | Description |
|----------|-----------------|
| ex00 | Exploratory Data Analysis & Feature Distribution Visualization |
| ex01 | Feature Selection & Target Correlation Analysis |
| ex02 | Multivariable Data Visualization & Feature Separation Analysis |
| ex03 | Data Preprocessing: Standardization (Z-score Normalization) |
| ex04 | Data Preprocessing: Feature Scaling & Min-Max Normalization |
| ex05 | Dataset Splitting & Train/Validation Sampling Strategies |

---
### 4 - Data Scientist 2

This module explores basic supervised classification models, data preprocessing (PCA, VIF feature selection), hyperparameter tuning, performance evaluation metrics, and ensemble methods like Voting Classifiers.

| Exercise | Description |
|----------|-----------------|
| ex00 | Model Evaluation Metrics & Confusion Matrix Implementation |
| ex01 | Correlation Analysis & Feature Relationship Heatmap Visualization |
| ex02 | Principal Component Analysis (PCA) & Explained Variance Thresholding |
| ex03 | Multicollinearity Detection & Feature Selection via Variance Inflation Factor (VIF) |
| ex04 | Tree-based Supervised Classification (Decision Trees / Random Forests) & Model Visualization |
| ex05 | Distance-based Classification (K-Nearest Neighbors) & Hyperparameter Tuning |
| ex06 | Ensemble Learning & Voting Classifier Implementation |
